# Employee Performance & Workforce Analytics — Excel Mini Project

## Project Overview
This project uses Microsoft Excel to analyze employee performance and workforce-related metrics. The workbook includes an employee dataset, formula-based categories, summary statistics, categorical analysis, pivot-style department summaries, and a dashboard.

## Dataset
- **Dataset sheet:** `Employee_Performance_Dataset`
- **Records:** 5,000 employee records (plus the header row)
- **Fields include:** employee ID, name, department, job role, performance score, KPI score, attendance, peer rating, task completion, work hours logged, manager feedback, training hours, promotion eligibility, performance category, and training category.

## Tools Used
- Microsoft Excel
- Excel formulas and functions
- Pivot-table-style summaries and charts/dashboard visuals

## Analysis Performed
- **Performance analysis:** reviewed employee performance scores by department.
- **Training analysis:** summarized training hours across departments.
- **Department analysis:** counted employees by department and calculated department percentages.
- **Descriptive statistics:** prepared summary measures such as mean, median, and minimum for selected numeric fields.
- **Calculated categories:** used nested `IF` formulas to classify performance and training levels.
- **Dashboard:** organized key workforce and performance insights into a visual dashboard.

## Excel Skills Demonstrated
- `IF` and nested `IF` formulas
- `AVERAGE`, `MEDIAN`, and `MIN`
- `COUNTIF` and percentage calculations
- Data summarization and department-wise comparisons
- Dashboard and chart presentation

## Workbook Structure
| Worksheet | Purpose |
|---|---|
| `cover` | Project cover page |
| `Employee_Performance_Dataset` | Main employee dataset |
| `summary_staticstics` | Descriptive statistics for numeric fields |
| `categorical Analysis` | Department counts and percentages |
| `pivot analysis` | Summary analysis |
| `training` | Department-wise training-hours summary |
| `performance` | Department-wise average performance summary |
| `Dashboard` | Visual dashboard |
| `chart_performance` | Supporting chart sheet |

## How to Use
1. Download or clone this repository.
2. Open the Excel workbook in Microsoft Excel.
3. Start with the `cover` sheet for the project title.
4. Review the `Employee_Performance_Dataset` sheet to understand the fields.
5. Explore the analysis sheets and dashboard for summarized insights.
6. If formulas or PivotTables do not refresh automatically, use **Formulas → Calculate Now** and refresh the relevant PivotTables in Excel.

## Project Goal
The goal of this mini project is to practice Excel-based data analysis and present employee performance and workforce metrics in a clear, structured dashboard.
